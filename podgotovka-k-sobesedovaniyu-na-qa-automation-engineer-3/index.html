Основы QA и тест-дизайна

1. Введение в QA

  1. Разница QA/QC/Testing
  2. Принципы тестирования (ISTQB)
  3. Жизненный цикл ПО (Waterfall, Agile, Scrum)

2. Уровни и виды тестирования

  1. Уровни: unit, integration, system, E2E
  2. Виды: функциональное, регресс, смоук, нагрузочное, security
  3. Тестирование в продакшене (canary, A/B)

3.Тест-дизайн: техники

  1. Эквивалентное разбиение, граничные значения
  2. Таблицы решений, попарное тестирование (pairwise)
  3. State transition, use case testing

4.Баг-репорты и тест-документация

  1. Структура баг-репорта (steps, expected/actual, severity/priority)
  2. Чек-листы, тест-кейсы, тест-планы: когда что использовать

5.Основы клиент-серверной архитектуры

  1. HTTP/HTTPS, методы (GET/POST/PUT/DELETE)
  2. Структура запроса/ответа, заголовки, cookies, статус-коды (2xx–5xx)
  3. REST vs SOAP (обзорно)

6.Введение в автоматизацию

  1. Пирамида тестирования (Martin Fowler)
  2. Что автоматизировать: критерии (стабильность, частота, ROI)
  3. Плюсы/минусы автоматизации, типичные ошибки

Язык программирования + Основы фреймворков

1. Базовый синтаксис

  • Переменные, типы данных (примитивные и ссылочные), операторы.

Управляющие конструкции

  • Условные операторы (if/else, switch), циклы (for, while, do-while).

3. Массивы и строки

  • Работа с массивами, класс String и его методы, StringBuilder.

4. Методы

Объявление, вызов, перегрузка методов, передача параметров.

5. Основы ООП (Объектно-Ориентированного Программирования)

  • Классы и объекты.
  • 4 столпа ООП: Инкапсуляция, Наследование, Полиморфизм, Абстракция.
  • Ключевые слова: this, super, static, final.
  • Абстрактные классы и интерфейсы.

6. Исключения (Exceptions)

  • Иерархия исключений, try-catch-finally, создание собственных исключений.

7. Дженерики (Generics)

  • Обобщения, wildcards (? extends, ? super).

8. Коллекции (Collections Framework)

  • Интерфейсы List, Set, Map.
  • Понимание, чем ArrayList отличается от LinkedList, HashSet от TreeSet, HashMap от TreeMap. Как они работают "под капотом".

9. Современная Java (Java 8+)

  • Лямбда-выражения, Stream API (фильтрация, маппинг, редьюсинг), Optional.

10. Ввод/Вывод (I/O и NIO)

  • Чтение и запись файлов, работа с путями.

11. Многопоточность, паттерны проектирования
